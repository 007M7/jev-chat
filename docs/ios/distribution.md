# 分发：别人怎么在自己的 iPhone 上用这个 App

**结论先说**：现在**没法直接把 IPA 发给别人装**。iOS 要求每个 App 用开发者证书签名，而证书只对**签名者自己的设备**有效——所以你编出来的包装不到别人手机上，别人编出来的也装不到你手机上。

下面是四条真实可行的路径，按成本与工作量排列。

---

## 路径 A：每个用户自己构建 + 自签（零成本，现状即可用）

这条不需要花一分钱，但每个用户都要自己做一遍我们做过的流程。

**对使用者来说的步骤**：

1. **拿到代码**：clone 或 fork 这个仓库（公开仓库，任何人可读可 fork）
2. **构建出未签名 IPA**：在他自己的 GitHub 仓库上跑 `.github/workflows/ios-unsigned.yml`
   （Actions → iOS 未签名 IPA → Run workflow）。公开仓库用标准 runner **免费**，
   产物在 Artifacts 里下载。
3. **装到手机**：
   - Windows：装 iTunes（web 版，负责 Apple 驱动）+ Sideloadly，用**自己的 Apple ID** 签名安装
   - macOS：可以用 AltStore / Xcode 直接装
   - **注意**：Sideloadly 要求 Apple ID 写国际区号格式（手机号注册的账号必须写 `+86...`），
     且不支持 App 专用密码
4. **手机上信任**：设置 → 通用 → VPN与设备管理 → 开发者App → 信任；另外要开**开发者模式**
5. **填自己的密钥**：App 里填 Jev 直连 key 与 DeepSeek key（只存本机 Keychain）

**代价与限制**（必须提前说清，否则用户会以为坏了）：

| 项 | 限制 |
|---|---|
| 有效期 | 免费 Apple ID 签出来的 App **只有 7 天**，到期要重签（AltStore 可自动刷新） |
| App 数量 | 同时最多 3 个自定义 App |
| App ID | 每周最多 10 个 |
| 系统要求 | 能装需 iOS 26+，但**采集功能要 iOS 27+**（ScreenCaptureKit 的 iOS 版从 27 才有） |
| 密钥 | 每人自备 Jev 与 DeepSeek 的 key，**不是装上就能用** |
| 准备时间 | 首次约 20~30 分钟（装驱动/工具占大半） |

**适合**：自己人、愿意折腾的早期用户、开发者试用。

---

## 路径 B：TestFlight（要 99 美元/年，但用户装起来最简单）

这是"给普通用户用"的正路。

1. 买 **Apple Developer Program**（$99/年）
2. App Store Connect 建 App → 上传构建（CI 里可以做签名与上传）
3. 邀请测试者：**最多 10,000 人**，可以发公开链接
4. 用户在 App Store 里装 **TestFlight**，点链接即可安装，**无需电脑、无需信任、无需开发者模式**

**代价**：每个构建 **90 天有效**，到期要传新构建；仍需每人自备 API 密钥。

**顺带的好处**：有了付费账号后，自己那台的签名也从 7 天变成 **1 年**。

---

## 路径 C：App Store 上架（要 99 美元/年 + 审核）

技术上可行，但**审核有不确定性，需要提前评估**：

- ✅ 有利面：录屏是**系统授权**的（走 `SCContentSharingPicker`，用户明确选择"整个屏幕"），
  App 没有 hook、没有注入、没有读别的 App 的数据、没有自动发送消息
- ⚠️ 不确定面：App 的用途是"读取其它 App 的聊天界面并给出回复建议"。
  审核可能关注它是否引导用户绕过其它 App 的服务条款（微信的许可协议）。
  这类"聊天辅助"工具在 App Store 上有先例，但过审没有保证。
- ⚠️ 另一个风险：如果同类的"外挂/自动化"工具被大量投诉，苹果可能一刀切

**建议**：想走这条路之前，先把定位写清楚——它是**用户自己屏幕内容的辅助阅读工具**，
不是对微信的插件，也不代替用户发送任何消息。这个定位在 README 与 App 内说明里都要一致。

---

## 路径 D：Ad-hoc / 企业分发（不适合本项目）

- **Ad-hoc**：$99/年 + 逐个登记设备 UDID（每年最多 100 台）。适合小范围熟人，
  但每次加人都要重新出包，且要收集别人的 UDID。
- **企业证书**：苹果只发给"有 D-U-N-S 号的企业、且 App 仅供内部员工使用"。
  个人项目拿不到，违规使用会被吊销。
- **欧盟的替代应用市场**（DMA 之后）：只在欧盟地区可用。

---

## 无论走哪条路，用户都要自备两样东西

1. **API 密钥**：Jev（判断）与 DeepSeek（视觉感知 + 起草）。当前 `providers.json` 里
   默认指向这两家，用户可以改成别的（加 provider 只改配置文件）。
2. **系统授权**：屏幕采集（每次开会话都要在系统选择器里确认一次）、通知、以及可选的
   相册写入权限。**开发者模式**在用免费账号自签时必须手动打开。

---

## 一句话总结

- **现在**：能用的分发方式是"**源码 + 每人自签**"，零成本但有 7 天有效期与手工门槛
- **想让普通人也能装**：买 $99 开发者账号走 **TestFlight**
- **想上架**：先解决定位表述，并接受审核的不确定性
