# 装包与 Gate 1 核对：你这边要做的具体步骤

预计 40~60 分钟（首次装 Apple 驱动占大半）。全程不需要 Mac、不需要开发者账号。
下面每一步都是"点哪里、看到什么、记什么"。

---

## 零、先清一件事：凭据不要发给我

- **Apple ID 只能你在 Sideloadly 里自己输**。它要的是你的账号密码，任何情况下不要贴到对话里。
- 之前你贴过两个 API key（Jev 的、DeepSeek 的），**建议去服务商后台轮换一次**——它们已经留在对话记录里了。

## 一、装两个工具（20~30 分钟，只需一次）

### 1. Apple 的 USB 驱动

Windows 不认 iPhone 就装不了。二选一：

- **推荐**：Microsoft Store 搜 **「Apple 设备」**（Apple Devices）安装 —— 它会带 USB 驱动
- 备选：从 apple.com 下载 **iTunes 经典安装包**（注意：**不要**装 Microsoft Store 版的 iTunes，它不带驱动）

装完**插上 iPhone**，在「此电脑」里应该能看到设备。看不到就先解决这一步，别往下走。

### 2. Sideloadly

从 <https://sideloadly.io/> 下载 Windows 版安装。

## 二、装包（10 分钟）

IPA 我已经下载到你本机了：

```
D:\jev\dist\JevAssistant-unsigned-probe5\JevAssistant-unsigned.ipa
```

（137 KB，`com.jev.assistant`，最低 iOS 27.0，已包含灵动岛扩展）

步骤：

1. iPhone 用数据线连电脑；手机上如弹出「信任此电脑」→ 点**信任**
2. 打开 Sideloadly
3. **IPA 那一栏**选上面那个文件的路径
4. **Apple ID 栏**填你的 Apple ID
   - 如果开了双重认证：Sideloadly 会提示要用**App 专用密码**。去 <https://appleid.apple.com> → 登录与安全 → App 专用密码 → 生成一个填进去（不要用主密码）
5. 点 **Start**。它会依次签主 App 和灵动岛扩展，然后推到手机上
6. 手机上：**设置 → 通用 → VPN与设备管理 → 开发者App** → 选你的 Apple ID → **信任**
7. 回到桌面，应该能看到「**Jev 助手**」

**如果报错**：
- 「bundle ID 冲突」→ 在 Sideloadly 里把 Bundle ID 改一下（比如加个后缀）
- 「不支持 app extension」→ 在 Sideloadly 设置里找 "Remove app extensions" / 类似选项勾上。**代价是灵动岛不能用了，但 Gate 1 的采集验证不受影响**，照样能测
- 免费账号的额度限制：**同时最多 3 个 App、每周最多 10 个 Bundle ID**。主 App + 扩展占 2 个

## 三、Gate 1 三个核对点（15 分钟，**这是重点**）

打开「Jev 助手」，界面上就有一张「Gate 1 核对清单」，你照着做：

### ① 授权是否每次都要重新确认？

1. 点**「开始采集（会弹出系统选择器）」**
2. 系统会弹内容选择器 → 选**「整个屏幕」**
3. 等它开始采集（状态变「采集中」，帧数开始涨）
4. 点**「停止采集」**，再点一次「开始采集」

**看什么**：第二次是**又弹出选择器要你重选**，还是**直接就开始采集了**？
**界面上怎么记**：那行有问题的那种选择题，选「每次都重新弹」或「只弹了第一次」。

> 影响：如果每次都重问，就是每次聊天前要点两下，退化成"半自动"。

### ② 有没有录屏指示条常驻？

采集状态下，**看屏幕顶部**（灵动岛/刘海两侧）：有没有常驻的红色/蓝色指示条或录屏标志？拍照或截图都行，界面上选「有，很明显 / 有但不明显 / 没有」，并在补充说明里写颜色和位置。

> 影响：这是体验问题，只有你能判断能不能接受。

### ③ 切到微信后还在收帧吗？（**命门**）

1. 保持采集状态，点 Home 或直接**切到微信**
2. 在微信里**停 30 秒以上**，期间**滑动一下聊天列表**（制造画面变化）
3. 切回「Jev 助手」

**看什么**：界面上那行会**自动给结论**：
- ✅ 显示「后台继续收帧：共 N 帧」→ **全自动路线成立**
- ❌ 显示「后台收不到帧」→ 全自动走不通，要改设计（改成截图触发）

> 这一行同时显示了"进后台/回前台"的帧数差，数据落盘了，所以切后台期间不会丢。

### 顺手再做两件事

**A. 验输出通道**（1 分钟）
点「**弹一条带 3 个候选的通知**」→ 会弹一条通知，上面有「候选 1/2/3」三个按钮。
- **切到微信**，让通知横幅浮在微信上方，确认能盖住
- 点其中一个候选按钮 → 该候选会进剪贴板（**不会发送**）→ 回微信长按输入框 → 粘贴，看能不能粘上
- 同时看**灵动岛**有没有出现 Jev 的状态（危险等级 + 最佳候选）

这一步同时验了"绝不自动发送"的红线：App 根本没能力往微信输入框写文本。

**B. 记两个数**
界面上会显示：
- **帧尺寸**（例如 `1179×2556`）—— 决定一次感知调用的图片体积与成本
- **放行去分析 N 次 / 共 M 帧** —— 这个比值就是成本控制在工作的证据。正常应该 M 远大于 N

再顺手点一次「**把最近一帧存到相册**」，相册里会出现一张截图——**你看一眼它到底截到了什么**（是整屏？包含微信？有没有把状态栏/灵动岛一起截进来）。这个信息我需要，因为它决定"消息区"在 iOS 上怎么定位。

## 五、7 天到期怎么续（重要）

免费账号签出来的 App **只有 7 天有效期**，过期后图标还在但打不开。两种续法：

- **手动**：到期时重复上面第二节的步骤（IPA 不用重新构建，同一个文件就行）
- **自动（推荐）**：装 **AltStore**，它在同一 WiFi 下会后台自动刷新签名，你基本不用管

## 六、另外还需要你给的两批数据

### 1. 一对一截图 3~5 张（用于验证基础场景）

之前你给的三张都是**群聊**，缺"我发的文字消息"这个最基本场景。请给：

| # | 场景 | 为什么 |
|---|---|---|
| 1 | 一对一 · 浅色主题 · 有来有回的文字 | 主力用例 |
| 2 | 一对一 · **深色主题** | 气泡底色变了，颜色类判定失效 |
| 3 | 含**表情包/图片**的对话 | 本地 OCR 结构上读不到，确认视觉模型的价值 |
| 4 | 一条**很长的折行消息** | 折行合并会不会出错 |

### 2. 群聊标注数据（用于校准群聊题目集）

群聊题目集现在标着 **`calibrated: false`**，而且已定位一处稳定矛盾（`need_reply=否` 却建议 `answer_directly`）。
修它**只能靠真实数据**，不能靠猜改措辞。

**你不需要从零写标注**。流程是这样，你的工作量很小：

1. 你发我 **5~10 张群聊截图**（不同话题、不同人的）
2. 我用现在的模型跑一遍，生成一张表：每条对话的模型判断（意图 / 对方想从我这里要什么 / 该不该回）
3. 你**只需要在错的那些上标一下你的答案**（对的不动）
4. 我拿这批数据跑 `calibrate.py`，出命中率与误差，再改措辞重新测

预计你花 15 分钟标注，就能让群聊档案从"仅供参考"变成可用。

## 七、做完之后我会做什么

| 你的结果 | 我的动作 |
|---|---|
| ③ 显示 ✅ 后台收帧 | 继续按原方案做：接感知 → 判断 → 通知/灵动岛，做完整闭环 |
| ③ 显示 ❌ 收不到帧 | 改设计：退回截图/分享触发，但保留坐标级归属与完整判断链（比纯快捷指令强） |
| ② 指示条明显 | 评估能否接受；不能的话考虑只在需要时短暂采集 |
| ① 每次都要重问 | 加"一次授权多次使用"的引导，或接受多点两下 |
| 一对一截图到位 | 跑真实场景准确率，验证基础路径 |
| 群聊标注到位 | 校准群聊题目集，把 `calibrated` 从 false 改 true |
